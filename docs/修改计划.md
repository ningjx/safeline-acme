## 第一梯队（本次实施）

- [x] **1. SAN 精确匹配修复**（建议 #7）✅ 2026-08-25
  - `acme_client.cert_sans` 不再剥离 `*.` 前缀，返回证书 SAN 完整集合
  - `tasks.py` 域名变更检测改为「配置域名集合」与「SAN 集合」精确比对
  - 修复：新增泛域名 `*.example.com` 到已有证书时永远不触发重新签发的 bug
  - 同步更新 `tests/test_scheduler.py` 场景 4c/4d（新增 4d 回归验证）

- [x] **2. 任务锁（per-domain）**（建议 #3）✅ 2026-08-25
  - `TaskRunner` 增加按托管域名的 `RLock` 表
  - `renew_and_push` / `delete_cert` 持域名锁执行，手动续期、定时任务、删除互斥于同一域名
  - 不同域名仍可并行；删除成功后清理该域名锁对象，防止泄漏

- [x] **3. Web Basic Auth**（建议 #1）✅ 2026-08-25
  - 新增环境变量 `WEB_AUTH_ENABLED`（默认 0，保持局域网免登录体验）、`WEB_AUTH_USERNAME`、`WEB_AUTH_PASSWORD`
  - `before_request` 对除 `/health` `/ready` 外的所有请求做 HTTP Basic Auth（`hmac.compare_digest` 常数时间比对）
  - `docker-compose.yml`（根与 dist）补充说明；README 更新权限模型

- [x] **4. Health Check**（附赠建议）✅ 2026-08-25
  - 新增 `GET /health`（存活探针）、`GET /ready`（组件配置状态，未配置也算 ready）
  - `docker-compose.yml`（根与 dist）增加 `healthcheck`
